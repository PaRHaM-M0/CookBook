# 🍳 آشپزخانه‌ی من — راهنمای مدیریت سایت

---

## 📂 ساختار پوشه‌ها

```
recipe-site/
├── index.html              ← صفحه‌ی اصلی (گالری، سرچ، فیلترها)
├── README.md               ← همین راهنما
├── assets/
│   ├── theme.css           ← استایل مشترک (رنگ، فونت، تم تاریک/روشن)
│   ├── home.css            ← استایل صفحه‌ی اصلی
│   ├── recipe.css          ← استایل صفحه‌ی هر دستور پخت
│   ├── app.js              ← منطق سرچ/فیلتر/تم/موبایل (لازم نیست دست بزنی)
│   └── recipes.js          ← ⭐ لیست غذاها — اینجا مدیریت می‌کنی
├── recipes/
│   ├── _template.html      ← قالب خالی برای ساختن صفحه‌ی غذای جدید
│   └── neapolitan-pizza.html
└── images/                 ← عکس‌های غذاها را اینجا بگذار
```

---

## ➕ اضافه‌کردن یک غذای جدید (۳ قدم)

### قدم ۱ — صفحه‌ی غذا را بساز
از `recipes/_template.html` یک کپی بگیر و اسمش را عوض کن، مثلاً:
`recipes/ghormeh-sabzi.html`. بعد محتوایش را پر کن (مواد اولیه، مراحل و…).

> در بالای فایل، داخل `<title>` اسم انگلیسی و اسم فارسی را کنار هم بگذار.

### قدم ۲ — غذا را به لیست اضافه کن
فایل `assets/recipes.js` را باز کن و یک بلوک جدید داخل `RECIPES` اضافه کن:

```js
{
  name: "Ghormeh Sabzi",                 // اسمی که روی کارت دیده می‌شود (انگلیسی)
  fa: "قورمه سبزی, خورش سبزی",           // اسم فارسیِ مخفی + اسم‌های مستعار (برای سرچ)
  desc: "خورش سنتی ایرانی با سبزی و لوبیا.",
  page: "recipes/ghormeh-sabzi.html",    // آدرس فایلی که در قدم ۱ ساختی
  image: "",                             // خالی = placeholder | یا "images/x.jpg"
  meal: "lunch",                         // نوع وعده
  cuisine: "iranian",                    // ملیت
  main: "meat",                          // ماده‌ی اصلی
  time: "long",                          // زمان پخت
  level: "medium",                       // سختی
  tags: ["خورش","سبزی","لوبیا"],         // برچسب‌های آزاد برای سرچ بهتر
  featured: false,                       // true = نشان «منتخب»
},
```

### قدم ۳ — تمام!
`index.html` را باز کن. کارت، سرچ و فیلترها **خودکار** ساخته می‌شوند.

---

## 🔍 درباره‌ی سرچ دوزبانه

- اسم انگلیسی روی کارت نمایش داده می‌شود.
- اگر **فارسی** سرچ کنی، چون اسم فارسی در فیلد `fa` (و در `<title>` صفحه) هست، غذا پیدا می‌شود.
- سرچ هوشمند است: «ی/ك» عربی، اعراب و نیم‌فاصله را خودش یکدست می‌کند.
- می‌توانی چند اسم مستعار را با کاما در `fa` بنویسی تا با هر کدام پیدا شود.

---

## 🎛️ کم/زیاد کردن فیلترها

همه‌ی دسته‌بندی‌ها در بالای `assets/recipes.js` در شیء `FILTERS` تعریف شده‌اند.
برای افزودن یک گزینه‌ی جدید، فقط یک سطر اضافه کن. مثلاً افزودن «سوپ» به وعده‌ها:

```js
soup: { label: "سوپ", ic:"🍜" },
```

> فیلترها فقط وقتی روی صفحه‌ی اصلی نشان داده می‌شوند که **حداقل یک غذا** از آن‌ها استفاده کرده باشد.
> یعنی صفحه هیچ‌وقت شلوغ نمی‌شود.

برای ساختن یک **گروه فیلتر کاملاً جدید** (مثلاً «رژیمی: گیاهی/بدون‌گلوتن»):
۱) یک گروه نو در `FILTERS` اضافه کن، ۲) همان کلید را در فیلد غذاها بنویس. تمام.

---

## 🖼️ اضافه‌کردن عکس

۱) فایل عکس را در پوشه‌ی `images/` بگذار.
۲) در `recipes.js` فیلد `image` را پر کن: `image: "images/pizza.jpg"`.
۳) برای عکس بزرگ بالای صفحه‌ی غذا، در فایل آن صفحه بلوک `ph-mark` را پاک کن و
   `<img src="../images/pizza.jpg" alt="...">` بگذار.

تا وقتی عکس نگذاری، یک placeholder تمیز نمایش داده می‌شود.

---

## 🗑️ حذف یا تغییر یک غذا

- **حذف:** بلوک آن را از `recipes.js` پاک کن (و در صورت تمایل فایل صفحه‌اش را).
- **تغییر ترتیب:** بلوک‌ها را در `recipes.js` جابه‌جا کن — ترتیب نمایش همان است.
- **ویرایش محتوا:** مستقیم فایل HTML همان غذا را در پوشه‌ی `recipes/` ویرایش کن.
